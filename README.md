# Trabalho de desenvolvimento de algoritimo: criação de um editor de textor
Código referente a um trabalho de desenvolvimento de código do 2° bimestre da disciplina de Algoritimos, ministrada pelo Professor Gustavo Naozuka, no curso de Ciência de Dados e Inteligência Artificial na Universidade Estadual de Londrina. 
O programa simula um editor de texto iterativo no terminal, que aceita diversos comandos.
